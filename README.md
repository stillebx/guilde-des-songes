# La Guilde des Songes — site vitrine

Site vitrine de La Guilde des Songes, association de jeu de rôle à Dijon.
Refonte du site https://www.laguildedessonges.net/ en Vite + Vue 3, page unique
(hero, qui sommes-nous, activités, infos pratiques, nous rejoindre).

## Développement

```sh
npm install
npm run dev
```

## Build de production

```sh
npm run build      # génère dist/ (site statique, déployable partout)
npm run preview    # sert le build localement
```
